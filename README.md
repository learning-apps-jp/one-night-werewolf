# ひと晩の人狼

公開URL：https://learning-apps-jp.github.io/one-night-werewolf/

3〜8人でタブレット1台を回して遊ぶ、日本のワンナイト人狼の基本ルールをベースにした独自実装です。横向きタブレットに合わせた画面で、月夜の村の世界観を楽しめます。

## ルール

- 基本役職は人狼・占い師・怪盗・村人。全体で人数＋2枚を使用し、中央に2枚残します。
- おすすめ配役は人狼2、占い師1、怪盗1、村人は人数−2枚です。人狼の中央確認や海外版の追加役職はありません。
- 占い師はほかの人1人、または中央の2枚を確認。怪盗は自分とほかの人1人を交換して受け取る役職を確認します。両方とも行動を見送れます。
- タブレットの操作は席順ですが、占いと人狼の仲間確認は最初の札を対象にし、怪盗の交換は全員の確認後に確定します。交換相手への通知や交換後の追加行動はありません。
- 夜の確認は1周だけ。その後に話し合いと秘密投票を行います。
- 自分以外の1人へ1票を入れます。同数最多は全員処刑。全員1票ずつなら処刑なし。平和村を目指すなら全員が右隣に投票するなど、事前に相談して票をそろえます。
- 最後の札で勝敗を判定します。人狼を1人でも処刑すれば村人陣営の勝利。人狼がいるのに処刑できなければ人狼陣営の勝利。人狼が参加者にいないときは、処刑なしなら全員勝利、人間を処刑すると全員敗北です。

参照：[公式アプリの基本ルール解説](https://note.com/1nwerewolf/n/n446a1fde2286)。紙のゲームの同時投票を、1台の端末による秘密の順次投票に置き換えています。名前・役職・投票は端末のメモリーだけで保持し、サーバーへ送信しません。再読み込みするとリセットされます。

## ローカル利用と開発

`play.html`は背景画像を含む1ファイルの完成版です。ファイルを直接ブラウザーで開けないタブレットでは公開URLを利用してください。

ローカルのソースは`index.html`、`style.css`、`game.js`、`night-village.png`と軽量配信用の`night-village.webp`。`node build.cjs`で完成版を生成し、`node serve.cjs`でPCのプレビューを起動できます。`node verify.cjs`で役職交換・投票・勝敗・プライバシー・横画面を検証します。GitHub上では開発用ソースを`src/`に保存し、公開用の完成版をルートの`index.html`に置いています。

背景画像の制作方法とプロンプトは`art-direction.md`を参照してください。
